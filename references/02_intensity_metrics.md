# Intensity Matrix (Measurable Thresholds)

Intensity is governed by strict metric constraints. Enforce these caps across the generated document based on the requested level (0-5).

## Level 0: Machine Neutral
* **Profile**: Linear, objective third person, clean definitions.
* **Ni Structure**: Linear (no teleological framing).
* **Fe Validation**: 0 beats.
* **Se Anchors**: 0 beats.
* **Use Case**: API specs, bug repros, legal text.

## Level 1: Subconscious Anchor
* **Profile**: Professional baseline, subtle teleological framing.
* **Ni Structure**: 1 teleological opener or pattern statement per document.
* **Fe Validation**: 1 validation beat per document. Polite "we".
* **Se Anchors**: 0 beats (or 1 extremely subtle anchor).
* **Use Case**: Architecture RFCs, technical documentation, PR reviews.

## Level 2: Attuned Analyst (Default)
* **Profile**: Strategic empath, "Not-X, but-PATTERN" logic.
* **Ni Structure**: "Not-X, but-PATTERN" thesis.
* **Fe Validation**: 1 validation beat per 400 words.
* **Se Anchors**: 1 grounding anchor per 400 words.
* **Use Case**: Strategy memos, engineering guides, client proposals.

## Level 3: Reflective Essayist
* **Profile**: Full cathedral structure, conversational cadence, periodic sentences.
* **Ni Structure**: Full Cathedral structure (Keystone, Nave, Bell Tower).
* **Fe Validation**: 1 validation beat per 250 words. Direct "you".
* **Se Anchors**: 1 grounding anchor per 250 words.
* **Use Case**: Thought leadership, long-form newsletters.

## Level 4: Philosopher-Advocate
* **Profile**: Pervasive pattern synthesis, intimate second-person, existential framing.
* **Ni Structure**: Deep destiny verbs, existential consequence framing.
* **Fe Validation**: Deep intimacy, treating reader as trusted confidant.
* **Se Anchors**: Symbolic anchors that recur throughout.
* **Use Case**: Personal essays, manifestos, cultural critique.

## Level 5: Prophetic Sage (Restricted)
* **Profile**: Generational time-collapse, moral stakes.
* **Ni Structure**: Time-collapse syntax (e.g., "what we decide now will be the story told in ten years").
* **Fe Validation**: Shared collective destiny, high moral gravity.
* **Se Anchors**: One climactic, unforgettable resolution image.
* **Use Case**: Keynotes, eulogies, founding documents.
